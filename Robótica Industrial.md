# Evaluación

| Actividad   | Porcentaje |
| ----------- |:----------:|
| Examen      |    100%    |
| Laboratorio |    10%     |
| Proyecto    |    30%     |
- No se evalúan asistencia, tareas ni series.
- A lo largo del semestre se dejarán actividades aleatorias y voluntarias de presentación ante la clase que permitirán ganar 1 punto sobre examen. Sólo se puede acumular 1 punto por estudiante antes de cada examen.
- De 4 a 5 exámenes, uno por tema dependiendo el tiempo del semestre:
	1. Conceptos
	2. Cinemática Directa e Inversa
	3. Control independiente de articulaciones
	4. Planeación de caminos y seguimiento de trayectoria
	5. Dinámica y Control
- Si no se aprueba el laboratorio, no se aprueba la materia.
- El proyecto sirve para mejorar una calificación "aprobatoria", por lo que el promedio de los exámenes debe ser superior a 5.5 para poder presentarlo.
